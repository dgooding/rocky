# Rocky — project handoff

A desk companion you can talk to and show things to. Local voice clone, local
brain, local vision, animated eyes. Nothing leaves the machine.

Last updated: 2026-10-21

---

## What works

| Piece | State |
|---|---|
| Voice clone (XTTS v2, Rocky) | working, ~1.1x realtime |
| Mic → speech-to-text (faster-whisper) | working, ~0.4s |
| Brain (Ollama `qwen3-coder:latest`, streaming) | working, ~0.1s warm to first token |
| Sentence/clause pipelining | working, speech starts on clause 1 |
| Eyes, 7 emotions, white sclera + black pupil | working |
| Webcam look (F3) + local vision | working, `qwen2.5vl:3b`, ~0.4s |
| macOS camera + mic permission | working **only via Rocky.app** |
| GUI text input | working |

Time from end of speech to first sound: **~2–3s** for a short opener.
That floor is XTTS itself: it renders at ~1.1x realtime, so Rocky cannot speak
faster than he talks.

## Run it

```sh
open -n /Applications/Rocky.app          # installed copy
# or, from the project (camera/mic fall back to the terminal's identity):
./venv/bin/python rocky_desktop_app.py
```

**Always launch via the .app** if you want the camera. macOS attributes camera
access to the app bundle; a bare `python` process has no bundle identity and is
silently denied.

Controls:

```
F1 hold / F2 toggle   talk (release F1 to send)
F3 or Space           look through the camera
type + Enter          talk by keyboard
1 – 7                 force an emotion (when the input line is empty)
Esc                   quit
```

Logs: `~/Library/Logs/Rocky.log` (bundle) or `$TMPDIR/rocky-desk.log`.
Last camera frame Rocky saw: `logs/last_look.jpg`.

`GET /health` returns `{"status":"ok","voice":"rocky"}`.

## Environment

- Python **3.11.17** in `./venv` (TTS caps at <3.12)
- TTS 0.22.0 (XTTS v2, weights in `~/Library/Application Support/tts`, 1.8 GB)
- faster-whisper 1.2.1 (`base.en`), sounddevice 0.5.6, pygame 2.6.1
- numpy **1.26.4** and opencv-python-headless **4.11** — see gotchas
- Ollama models: `qwen3-coder:latest` (brain, 30B MoE), `qwen2.5vl:3b` (vision), `llama3.2:3b` (fast fallback), `moondream` (worse vision; kept only as a fallback)
- Brain context is pinned to **8192** (`--brain-context`). qwen3-coder's
  262k default reserves ~45 GB; 8k keeps it at ~19 GB with no quality loss
  for one-line replies.

Voice server:

```sh
COQUI_TOS_AGREED=1 ./venv/bin/python rocky_say.py --server start   # ~27s to load
./venv/bin/python rocky_say.py --server stop
```

Hosted brain is supported but unused (no keys on this machine):

```sh
./venv/bin/python rocky_desktop_app.py --brain-api openai \
  --brain-url https://api.deepseek.com/v1 --brain-model deepseek-chat --brain-key $KEY
./venv/bin/python rocky_desktop_app.py --brain-api anthropic \
  --brain-url https://api.anthropic.com/v1 --vision-model claude-sonnet-4-5 --brain-key $KEY
```

## Gotchas (all cost real time to find)

1. **`exec` in an .app launcher breaks camera permission.** `exec python ...`
   replaces the bundle process, so macOS attributes the capture to bare Python
   and silently denies (Settings shows nothing to toggle). The launcher must
   stay alive as the parent.
2. **numpy must stay < 2.** `gruut` (a TTS dependency) requires it. Installing
   current OpenCV silently upgraded numpy to 2.x and would have broken XTTS on
   the next restart. Keep `opencv-python-headless<5` + `numpy<2`.
3. **The voice server is single-threaded.** Two callers (app + a test script)
   queue behind each other; a 1.2s synthesis can look like 12s. Not a bug.
4. **XTTS conditioning** is computed once at server start and reused
   (`get_conditioning_latents` + `inference()`); the original per-request
   `tts_to_file` was slower. `ROCKY_SPEED` (default 1.25) shrinks both audio
   length and generation time.
5. **Local vision models:** non-streamed requests only — moondream drops its
   first character when streamed ("urn of coffee"). And qwen hallucinates at
   temperature 0.6 ("you are holding a guitar"); 0.1 with a neutral prompt is
   accurate and consistent.
6. **Eyes:** pupil is drawn into the sclera before the lids punch transparent
   holes, so it is clipped cleanly; the pupil also follows the *visible* band,
   which is what makes sleepy look down instead of smiling. Bloom is derived
   from the masked eye, so lids do not glow.

## Rebuild from scratch

```sh
brew install python@3.11
python3.11 -m venv venv
./venv/bin/pip install "numpy<2" "opencv-python-headless<5" \
    TTS faster-whisper sounddevice soundfile pygame scipy
ollama pull qwen3-coder
ollama pull qwen2.5vl:3b
COQUI_TOS_AGREED=1 ./venv/bin/python rocky_say.py --server start   # downloads XTTS v2
```

Then copy `Rocky.app` to `/Applications`, re-sign and grant permissions once:

```sh
codesign --force --sign - --identifier com.aiserver.rocky /Applications/Rocky.app
open -n /Applications/Rocky.app --args --snap /tmp/cam.jpg
```

## Verify without a human

```sh
./venv/bin/python rocky_eyes.py --selftest shots/eyes        # one PNG per emotion
./venv/bin/python rocky_desktop_app.py --selftest            # stt + brain + vision + UI states
open -n /Applications/Rocky.app --args --snap /tmp/cam.jpg   # camera permission
curl -s http://127.0.0.1:59720/health
```

## Not done

- **Sub-second speech.** Would need a streaming TTS (Piper: ~0.2s start, but
  loses the clone) or a much smaller XTTS chunk size. Everything else is ready.
- **Hardware.** The eye presets are ported from Casey Grothaus's desk robot
  (`github.com/cgro00/desk-robot`, MIT). For an ESP32 build: GC9A01 1.28"
  240x240 round displays + XIAO ESP32-S3. `rocky_eyes.py` mirrors his
  `paramsFor()` table, so the presets port straight back to C++.
- **Installing to `/Applications` kept the camera grant** (verified with `--snap`).
  If macOS ever re-prompts after a re-sign, allow it once; the bundle ID stays
  `com.aiserver.rocky`.
